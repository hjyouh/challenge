🌐 구글 크롬 (Chrome) 에 홈화면 설치

  1. 크롬 앱으로 원하는 웹페이지에 접속합니다.
  2. 우측 상단 점 3개 메뉴(⋮) 선택.
  3. 홈 화면에 추가를 선택.
  4. 바로가기 이름을 입력하고 추가.
  5. 팝업창이 뜨면 자동으로 추가를 누르거나 아이콘을 길게 눌러 원하는 위치에 배치.

🍎 아이폰 사파리에 홈화면 설치

  1. 사파리 하단 주소 옆 (...) 아이콘을 선택
  2. 공유 아이콘 선택
  3. 더보기 아이콘 선택
  4. 홈 화면에 추가 선택

홈화면에 아이콘이 생성이 됩니다.

📱 삼성 인터넷 브라우져에 홈화면 설치

  1. 삼성 인터넷 앱으로 웹페이지에 접속
  2. 우측 하단 줄 3개 메뉴(☰)를 선택
  3. 현재 페이지 추가를 선택
  4. 목록에서 홈 화면을 선택
  5. 추가를 눌러 완료 후 홈화면에 아이콘 생성
